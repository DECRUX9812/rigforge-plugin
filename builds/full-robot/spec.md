## Firmware

```cpp
/* Mobile manipulator · 419mm reach on a 130mm 4WD base — ESP32-S3 DevKitC-1
 * Generated by Rigforge: mobile manipulator, 6 arm servos on a
 * PCA9685 + 4 driven wheels. One pack, one loop, one arbiter.
 */
#include <Wire.h>
#include <Adafruit_PWMServoDriver.h>

Adafruit_PWMServoDriver pwm = Adafruit_PWMServoDriver(0x40);

// ── drive ──────────────────────────────────────────────────────────────────
// Pin numbers come from the analysis pass — the PINS tab and this file cannot drift.
const uint8_t PWM_L = 1, IN1_L = 2, IN2_L = 10;
const uint8_t PWM_R = 15, IN1_R = 16, IN2_R = 17;
const float   TRACK = 0.312;
const float   VMAX  = 1.21;

// ── arm ────────────────────────────────────────────────────────────────────
const uint8_t JOINTS = 6;
const int16_t LIMITS[][2] = { {-160, 160}, {-80, 80}, {-135, 135}, {-100, 100}, {-180, 180}, {-90, 90} };
int16_t target[6] = {0};
int16_t current[6] = {0};

float speedNow = 0.0f;

void writeJoint(uint8_t i, int16_t deg) {
  uint16_t us = 500 + (uint32_t)((deg + 180) * 2000) / 360;
  pwm.setPWM(i, 0, (uint16_t)((us / 20000.0) * 4096));
}

void setMotor(uint8_t ch, uint8_t in1, uint8_t in2, float cmd) {
  cmd = constrain(cmd, -1.0f, 1.0f);
  digitalWrite(in1, cmd > 0.02f);
  digitalWrite(in2, cmd < -0.02f);
  ledcWrite(ch, (uint8_t)(fabsf(cmd) * 255));
  speedNow = fabsf(cmd) * VMAX;
}

void drive(float v, float w) {
  setMotor(0, IN1_L, IN2_L, (v - w * TRACK / 2) / VMAX);
  setMotor(1, IN1_R, IN2_R, (v + w * TRACK / 2) / VMAX);
}

void stop() { setMotor(0, IN1_L, IN2_L, 0); setMotor(1, IN1_R, IN2_R, 0); }

void setup() {
  Serial.begin(115200);
  Wire.begin(8, 9);
  pwm.begin();
  pwm.setPWMFreq(50);
  ledcAttach(PWM_L, 20000, 8);
  ledcAttach(PWM_R, 20000, 8);
  pinMode(IN1_L, OUTPUT); pinMode(IN2_L, OUTPUT);
  pinMode(IN1_R, OUTPUT); pinMode(IN2_R, OUTPUT);
  stop();
  for (uint8_t i = 0; i < JOINTS; i++) writeJoint(i, 0);
  Serial.println("Mobile manipulator · 419mm reach on a 130mm 4WD base ready — 'D v w' to drive, 'J i deg' to pose, 'S' to stop");
}

void loop() {
  // The arbiter: reaching while moving is what tips this machine over. Below
  // 0.25 VMAX the arm is free, above it the arm is held and targets are refused.
  static uint32_t lastCmd = 0;
  if (Serial.available()) {
    char c = Serial.read();
    if (c == 'D' || c == 'd') {
      float v = Serial.parseFloat(), w = Serial.parseFloat();
      drive(v, w);
      lastCmd = millis();
    } else if (c == 'J' || c == 'j') {
      int idx = Serial.parseInt(), deg = Serial.parseInt();
      if (speedNow > 0.25f * VMAX) {
        Serial.println("refused: arm locked while driving");
      } else if (idx >= 0 && idx < JOINTS) {
        target[idx] = constrain(deg, LIMITS[idx][0], LIMITS[idx][1]);
      }
    } else if (c == 'S' || c == 's') {
      stop();
      for (uint8_t i = 0; i < JOINTS; i++) target[i] = current[i];
    }
  }
  if (millis() - lastCmd > 800) stop();   // lost client = stop, never wander

  for (uint8_t i = 0; i < JOINTS; i++) {
    if (current[i] == target[i]) continue;
    current[i] += (target[i] > current[i]) ? 1 : -1;
    writeJoint(i, current[i]);
  }
  delay(8);
}
```

## Assembly

1. **Print the frame** (59.8 h) — 21 printed parts, 1367g PETG, 60h on a 0.4mm nozzle at 0.2mm layers. Orient load-bearing links so layer lines run along the load, not across it. _Tools: printer, slicer._
2. **Build the base** (40 min) — Deck, rails and bulkheads first, then the four motors. Check the deck is flat to within a millimetre — the arm bolts to it, and a twisted deck becomes a leaning robot. _Tools: M3 hex key, square._
3. **Assemble the arm on the bench** (50 min) — Arm first, base second: build the turret, shoulder, upper arm and forearm as one assembly and test it with a bench supply. Lifting a whole robot to fix a binding joint is how backs and robots both break. _Tools: M3 hex key, bench supply._
4. **Bolt the arm to the deck** (20 min) — Four bolts through the turret flange into heat-set inserts, threadlocker on all four, then check the arm can sweep its full yaw range without the head or the pack in the way. _Tools: threadlocker._
5. **Power and harness** (45 min) — Split the servo rail from the drive rail: two UBECs, one per side of the deck. Route the arm bundle down through the turret centre so yaw never pulls a wire. _Tools: soldering iron, cable ties._
6. **Ballast and stability test** (15 min) — With the arm at full extension, lift one wheel at a time and confirm the other three stay planted.
7. **Bring up the MCU** (15 min) — Flash the generated sketch. Open the serial monitor at 115200 and confirm you see the boot line before you send any command. _Tools: USB-C cable, arduino-cli._
8. **Load test** (20 min) — Run the machine unloaded for 5 minutes, then measure current at the pack: typical should be ~5.1A, and no connector should be more than hand-warm. _Tools: multimeter / clamp meter._
9. **Verify limits** (15 min) — Walk every joint to its soft limit slowly and confirm the firmware stops it. All sizing checks passed at build time.

## Design notes

- Shoulder pitch runs a 2:1 GT2 stage: Feetech STS3215 serial bus servo gives 1.59 N·m at the horn, 2.94 at the joint.
- Drive: JGB37-520 12V 178rpm + encoder — 0.11 N·m per wheel needed for 3.6kg, 1.18 N·m available.
- Arm holds 1kg at 42cm reach with a 1.7× factor; the base is what limits it, not the servos.
- The arm shadows the head camera at full reach. The pan joint is there for exactly that: yaw the head 60-90° away from the boom, or mount the camera pod off-centre on the next revision.
- Deck is 389mm: print it in two dovetailed halves, or cut it from 3mm aluminium — same mass, no warp, no 40-hour print.
